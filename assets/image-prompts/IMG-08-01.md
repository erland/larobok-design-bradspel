# Bildprompt IMG-08-01

Skapa en fristående professionell läroboksillustration för en svensk bok om brädspelsdesign.

Motiv: ett enkelt snabbspel i skattjakts-/äventyrstema på ett bord. Visa två nästan identiska små prototypuppställningar sida vid sida: version A och version B antyds visuellt genom små skillnader i karta, farokort eller tidsmätare. Fokus ska vara på idén att en liten justering testas i taget för att förbättra balans och speltempo.

Stil: ren, tydlig, pedagogisk, varm hobbykänsla, redaktionell illustration.

Viktigt:
- fristående illustration, inte A4-sida
- ingen ram runt bilden
- ingen affischlayout
- ingen bakgrundsplansch
- ingen titel, rubrik, sidfot eller marginaldesign
- ingen text i bilden, förutom eventuellt mycket enkla symboler
- vit eller diskret bakgrund
- inga realistiska varumärken
